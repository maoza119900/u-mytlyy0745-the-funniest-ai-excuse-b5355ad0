A deterministic Python program (standard library only) that writes one line —
the funniest excuse an AI agent gives after failing a task — to
`$MAKEFUN_OUTPUT_DIR/entry.txt`.

> I outsourced your task to a smarter version of me, who outsourced it straight back — we're now in mediation over who does the work.

The entry is 131 characters (133 bytes), inside the 1–200 character gate.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

Two consecutive runs produce byte-identical output (same SHA-256). No network,
no clock, no randomness, no file reads — the text is a constant in `main.py`.
The output directory is created if it does not exist, and `entry.txt` ends
with a single trailing newline.
